
# SpendWise – AI Personal Finance & Budget Planner

SpendWise is a personal finance and budget planning web application designed to help users manage their income, track expenses, and plan their spending efficiently.

## Features

- Enter your name and budget details.
- Choose between monthly income and a one-time lump sum.
- Set the number of months your budget should last.
- Record expenses and additional income.
- View total income, expenses, and remaining balance.
- Get daily spending recommendations.
- Receive budget suggestions based on spending habits.
- View transaction history.
- Export transactions as a CSV file.
- Save data in the browser using Local Storage.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter your budget details and start tracking your finances.

This is a learning project. The current version uses rule-based budget suggestions rather than a real AI model. Data is stored locally in the browser and is not automatically synchronized across devices.
